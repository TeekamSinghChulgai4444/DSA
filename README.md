# Data Structures & Algorithms (DSA) Practice

Welcome to my **Data Structures and Algorithms** repository! This repo tracks my daily practice, core implementations, and problem-solving journey across various fundamental topics and LeetCode problems.

## 📂 Repository Structure

The project is organized by topics and data structures:

| Folder | Description |
| :--- | :--- |
| **`BIT_MANIPULATION`** | Bitwise operators, bitmasks, and binary trick problems |
| **`DP1`** | Dynamic Programming patterns, optimization, and subproblems |
| **`GRAPH1`** | Graph algorithms (BFS, DFS, shortest path, topological sort) |
| **`HEAP`** | Min/Max Heaps, priority queues, and top-K element problems |
| **`LEETCODE`** | Solved LeetCode coding challenges categorized by difficulty |
| **`LINKEDLIST`** | Singly, doubly, and circular linked list implementations |
| **`QUEUE`** | Queue operations, double-ended queues (Deque), and applications |
| **`RECURSION`** | Backtracking, recursion trees, and recursive problem-solving |
| **`SEGMENT_TREE`** | Range query trees, point updates, and segment tree implementations |
| **`STACK`** | Stack-based algorithms (monotonic stack, evaluation of expressions) |
